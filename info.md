# Nimly Manager

Administrer Nimly-låser i Home Assistant gjennom Zigbee2MQTT, med lokal og
hendelsesverifisert registrering av fingeravtrykk.

Integrasjonen bruker Home Assistants eksisterende MQTT-tilkobling. Den åpner
ikke en egen broker-forbindelse og lagrer ikke rå PIN-, RFID- eller
fingeravtrykksdata.

Se [README](https://github.com/aridder/nimly-manager#readme) for installasjon,
oppsett og kjente begrensninger.
